## 개인 프로젝트 데이터 및 주제 선정

### 주제

**초등학교 통학구역 위험요소 관리 Web GIS**

초등학교와 통학구역 공공데이터를 기준정보로 활용하여 학교별 통학구역을 지도에서 조회하고, 사용자가 통학로의 위험지점과 위험구간을 직접 등록·조회·수정·삭제할 수 있는 Web GIS 서비스를 구현합니다.

### 활용 데이터

#### 한국교육시설안전원 초등학교통학구역

* 초등학교 학구별 통학구역 SHP 제공
* 통학구역 Polygon 구축 및 지도 표시에 활용

https://www.data.go.kr/data/15159265/fileData.do

#### 한국교육시설안전원 학교학구도연계정보

* 학교ID와 학구ID 연계정보 제공
* 학교와 통학구역을 연결하는 데 활용

https://www.data.go.kr/data/15159266/fileData.do

#### 전국초중등학교위치표준데이터

* 학교명, 학교ID, 위도·경도 제공
* 초등학교 위치 Point 구축에 활용

https://www.data.go.kr/data/15021148/standard.do

#### 전국어린이보호구역표준데이터

* 어린이보호구역 위치 및 관련 정보 제공
* 어린이보호구역 Point 레이어 표시에 활용

https://www.data.go.kr/data/15012891/standard.do

#### 전국CCTV표준데이터

* CCTV 위치 및 설치정보 제공
* CCTV Point 표시 및 통학구역 내부 CCTV 조회에 활용

https://www.data.go.kr/data/15013094/standard.do

### CRUD 활용 방향

공공데이터는 학교, 통학구역, CCTV 등 기준정보로 활용하고, 사용자가 직접 등록한 위험요소를 별도 데이터로 관리합니다.

* **Create**: 통학로의 위험지점(Point)과 위험구간(LineString) 등록
* **Read**: 학교별 통학구역 및 통학구역 내부 위험요소 조회
* **Update**: 위험유형, 설명, 위치, 처리상태 등 위험요소 정보 수정
* **Delete**: 잘못 등록되었거나 더 이상 관리가 필요하지 않은 위험요소 삭제
