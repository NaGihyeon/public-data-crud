# 초등학교 통학안전 점검 관리 Web GIS

## 프로젝트 소개

강서양천교육지원청의 통학로 안전업무 담당자가 관할 초등학교 주변의 어린이 교통사고 다발지역과 교통안전시설을 지도에서 확인하고, 현장점검이 필요한 후보를 검토하여 점검 결과와 후속 조치이력을 관리하는 Web GIS 서비스입니다.

`점검 후보 확인 → 점검대상 선정 → 현장점검 → 결과 등록 → 후속조치 관리`

업무 흐름을 지원하는 것을 목표로 합니다.

## 주요 사용자

- 강서양천교육지원청 학교통합지원과 통합지원1팀의 통학로 안전업무 담당자

## 서비스 범위

- 대상 지역: 서울특별시 강서구·양천구
- 대상: 강서양천교육지원청 관할 초등학교
- 분석 범위: 학교 Point 기준 300m
- 300m Buffer는 공식 어린이보호구역이 아닌 프로젝트상의 분석범위로 사용

## 점검 후보 도출

학교 300m 분석범위와 어린이 사고다발지역 Polygon의 공간 중첩 여부를 분석하여 현장점검 검토 후보를 도출합니다.

- 어린이보호구역 내 어린이 교통사고 다발지역
- 보행어린이 교통사고 다발지역

횡단보도, 보행신호등, 험프 등의 안전시설은 위험도를 자동 판정하는 기준이 아닌 담당자의 검토 근거정보로 활용합니다.

## 주요 기능

- 관할 초등학교 조회 및 검색
- 학교 주변 사고다발지역 조회
- 점검 검토 후보 도출
- 횡단보도·보행신호등·험프 등 안전시설 조회
- 점검 상태 관리
- 현장점검 결과 CRUD
- 개선 필요사항 및 후속조치 관리
- 학교별 점검·조치이력 조회

## 공간정보 활용

PostGIS를 활용하여 학교 300m 분석범위와 사고다발지역 Polygon의 공간 중첩을 분석하고, 결과를 Web GIS 지도에서 제공합니다.

## 프로젝트 방향

본 프로젝트는 사고 위험도를 자동 판정하는 시스템이 아니라, 공공데이터와 공간분석을 활용하여 현장점검 대상 선정과 점검·후속조치 관리를 지원하는 업무지원 Web GIS를 목표로 합니다.
