# 초등학교 통학안전 점검 관리 Web GIS

## 프로젝트 소개

서울특별시 초등학교 주변의 어린이 교통사고 다발지역과 교통안전시설, 실시간 교통정보를 지도에서 확인하고, 현장점검이 필요한 후보를 검토하여 점검 결과와 개선·후속조치 이력을 관리하는 Web GIS 프로젝트입니다.

`점검 후보 확인 → 점검대상 선정 → 현장점검 → 개선 필요사항 → 후속조치 관리`

업무 흐름을 지원하는 것을 목표로 합니다.

## 주요 사용자

- 일반 사용자
- 교육지원청 담당자
- 관리자

## 서비스 범위

- 대상 지역: 서울특별시 전체
- 대상: 서울특별시 소재 운영 초등학교
- 분석 범위: 학교 Point 기준 300m
- 300m Buffer는 공식 어린이보호구역이 아닌 프로젝트상의 분석범위

## 점검 후보 도출

학교 300m 분석범위와 어린이 사고다발지역 Polygon의 공간 중첩 여부를 분석하여 `학교 × 사고다발지역` 단위의 점검 검토 후보를 생성합니다.

- 보행어린이 교통사고 다발지역
- 어린이보호구역 내 어린이 교통사고 다발지역

횡단보도, 보행신호등, 과속방지턱, 실시간 돌발정보, 교통 CCTV는 후보 자동 생성 기준이 아닌 담당자의 판단을 위한 참고정보로 활용합니다.

## 주요 기능 (설계 기준)

- 서울시 초등학교 및 자치구 지도 조회
- 학교 300m 분석범위 조회
- 사고다발지역 및 안전시설 조회
- 안전시설 레이어 ON/OFF
- 실시간 돌발정보 조회
- 교통 CCTV 조회
- 점검 검토 후보 생성 및 관리
- 현장점검 결과 관리
- 개선 필요사항 및 후속조치 관리
- 학교별 점검·조치 이력 조회

## 공간정보 활용

PostGIS를 활용하여 학교 Point 기준 300m 분석범위를 생성하고, 사고다발지역과의 중첩 및 교집합을 분석합니다.

안전시설·실시간 돌발정보·CCTV는 학교 300m 범위를 기준으로 공간조회하도록 설계했습니다.

## 현재 구현 현황

- 안전시설 데이터 적재 및 지도 레이어 조회
- 자치구 경계 지도 표시
- 실시간 돌발정보 API 연동 및 DB 동기화
- 교통 CCTV 데이터 적재 및 지도 표시
- 학교·어린이보호구역 및 업무 테이블 DB 스키마 구성
- 프로젝트 초기 DB 구축 SQL 통합

사고다발지역 API 연동, 후보 자동 생성, 점검·개선·후속조치 CRUD 및 Quartz 정기 동기화는 후속 구현 대상입니다.
